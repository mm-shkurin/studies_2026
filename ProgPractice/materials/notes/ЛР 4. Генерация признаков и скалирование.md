# ЛР 4. Генерация новых признаков. Скалирование данных

<!-- path: disciplines/programming-workshop-bachelors-5sem/labs/generation; updated-at: 2026-11-06T16:40:29.951Z; author-name: Иван Бугаенко -->

Источник: https://wiki.pmifi.ru

## [¶](#задание) Задание

1. Выполнить процедуру генерации новых признаков.
2. Решите проблему диспропорции признаков, если она наблюдается в данных.
3. Выполнить процедуру построения baseline-моделей.

## [¶](#ход-работы) Ход работы

1. Работа с разделом 2 шаблона ml-проекта (генерация новых признаков).

- Сформируйте новые признаки для train и test выборок, используя доступные методы генерации (если есть возможность найти формулы для прикладной области -- это отличный вариант, в противном случае, используйте математические операции и функциональные преобразования, если есть временные метки, сгенерируйте лаговые или разностные признаки).
- Определите, есть ли в данных проблема диспропорции признаков. Если она присутствует, разрешите ее при помощи скалирования.

2. Работа с разделом 3 шаблона ml-проекта (выбор ML-моделей): обучите dummy-модели (sklearn.dummy), которые можно использовать в качестве baseline-подхода.

## [¶](#критерии-приемки-базовый-минимум) Критерии приемки (базовый минимум)

1. Студент может объяснить все действия, которые сделал в рамках работы.
2. Работа оформлена аккуратно и читаемо, используются markdown-ячейки, а не комментарии в коде.
3. В ноутбуке присутствуют: генерация новых признаков, рассмотрение проблемы диспропорции.
4. Обучена baseline-модель в разделе 3.
