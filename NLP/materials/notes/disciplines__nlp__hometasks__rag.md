# Интеллектуальный поиск (RAG)

## Цель работы

Разработать приложение для интеллектуального поиска с применением больших языковых моделей (LLM) и подхода [Retrieval Augmented Generation (RAG)](https://habr.com/ru/articles/779526/).

## Смысл

Большие языковые модели сегодня активно применяются в коммерческих IT-продуктах, в том числе в замкнутом корпоративном контуре. Одним из наиболее распространенных кейсов языкового моделирования являются вопросно-ответные системы. Решения на базе RAG сегодня являются стандартом генеративных реализации генеративных вопросно-ответных систем.

## Задачи

- **определиться** с приложением: это может быть мобильное приложение, чат-бот, веб-приложение, приложение для ПК и т. д.
- **ознакомиться** с базовыми возможностями фреймворка [LangChain](https://www.langchain.com/) ([Document loaders](https://python.langchain.com/docs/integrations/document_loaders/), [Embeddings](https://python.langchain.com/docs/integrations/text_embedding/), [Chat Models](https://python.langchain.com/docs/integrations/chat/), [Retrievers](https://python.langchain.com/v0.1/docs/modules/data_connection/retrievers/))
- **подготовить** (собрать, загрузить) базу знаний: это могут быть файлы PDF, ссылки в сети Интернет, пространства в Notion и другое
- **развернуть** локально LLM с использованием [Ollama](https://github.com/ollama/ollama) / [llama.cpp](https://github.com/ggerganov/llama.cpp) **либо использовать** [GigaChat API](https://developers.sber.ru/portal/products/gigachat-api) (в этом случае рекомендуется рассмотреть фреймворк [GigaChain](https://github.com/ai-forever/gigachain) - расширение LangChain)

> При использовании GigaChat API бесплатно предоставляется около 1 млн. токенов. Этого должно хватить для выполнения задания. Преподаватель **не поддерживает** покупку платных пакетов.

- **реализовать** подход RAG для [поиска ответов на вопросы по собранной базе документов](https://python.langchain.com/docs/tutorials/local_rag/)
- **разработать** приложение-обёртку для реализованного RAG
- **оформить** отчёт

## Важные замечания

- вы можете использовать **любые** большие языковые модели **с открытыми весами;** рекомендуется попробовать [Llama3.1](https://ollama.com/library/llama3.1) и [Mistral](https://ollama.com/library/mistral) (модели в Ollama либо [квантованные версии с Hugging Face](https://huggingface.co/bartowski/Meta-Llama-3.1-8B-Instruct-GGUF))
- для локального запуска больших языковых моделей у вас должно быть **минимум 8 ГБ оперативной памяти**
- LangChain является рекомендуемым решением для разработки ядра вопросно-ответной системы, однако вы можете использовать другие фреймворки (например [LlamaIndex](https://www.llamaindex.ai/))
- задание предполагает реализацию **RAG в базовом варианте** (загрузка документов, разделение их на чанки, векторизация чанков, размещение чанков в векторном хранилище, организация цепочки для извлечения релевантных чанков и получения ответа на вопрос), использование продвинутых техник RAG (MMR, Reranking, Ensemble retriever и др.) **не требуется**

> Домашнее задание считается выполненным, если оно загружено через электронный кабинет ОмГТУ и принято преподавателем

> Преподаватель оставляет за собой право отклонить работу, если оформление отчёта не соответствует требованиям нормоконтроля

- **заключение** (1 страница)
