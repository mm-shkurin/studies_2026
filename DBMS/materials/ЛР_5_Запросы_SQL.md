# Лабораторная работа №5. Построение запросов с использованием инструкций SQL

Источник: методика рейтингового контроля, п. 5 (срок — 11, макс. 8,5 балла); учебное пособие, ЛР 6 (стр. 100–117).

## Задание

1. Изучить стр. 100–117 в учебном пособии, выполнить учебные примеры на стр. 101–117.
2. Согласно индивидуальному варианту РГР по дисциплине «Базы данных» выполнить Лабораторную работу №5 и оформить в виде отчета (формулировки SQL-запросов; скрипты SQL-запросов; скриншоты выполнения SQL-запросов, которые пронумерованы). Для созданной БД построить:
   - 2.1. запрос с использованием всех типов соединений;
   - 2.2. запрос с использованием оператора DISTINCT;
   - 2.3. запрос с использованием оператора BETWEEN;
   - 2.4. запрос с использованием оператора LIMIT;
   - 2.5. запрос с использованием оператора OFFSET;
   - 2.6. запрос на выборку, содержащий шаблоны поиска на основе LIKE, NOT LIKE;
   - 2.7. запрос на выборку с регулярным выражением POSIX;
   - 2.8. запрос на получение агрегированных данных (любые три статистические функции);
   - 2.9. запрос на выборку, содержащий вложенный запрос;
   - 2.10. запрос с использованием условного выражения CASE;
   - 2.11. запрос на выборку, в котором реализована группировка данных и простая сортировка;
   - 2.12. запрос на выборку, в котором реализована группировка данных с условием и многоуровневая сортировка.
3. После защиты лабораторной работы в аудитории выслать на e-mail преподавателя отчет и соответствующие файлы.
