# ЛР 5: Построение запросов с использованием инструкций SQL

## Структура решения

- `queries.sql` — 12 SQL-запросов по заданию ЛР 5

## Проверка запуском

Требуется запущенный контейнер PostgreSQL 15 в Docker:

```bash
# Запуск контейнера (если не запущен)
docker start dbms-pg

# Выполнение запросов в базе formula1
docker exec -i dbms-pg psql -U postgres -d formula1 < solution/lab5/queries.sql
```

## Запуск в pgAdmin

1. Открыть pgAdmin 4
2. Подключиться к базе `formula1`
3. Открыть Query Tool
4. Открыть файл `solution/lab5/queries.sql`
5. Выполнить запросы по очереди (каждый запрос отдельно)
6. Сделать скриншоты результатов выполнения (пронумеровать)

## Описание запросов

### 2.1. Запросы с использованием всех типов соединений

- **INNER JOIN**: пилоты и их команды (только совпавшие строки)
- **LEFT JOIN**: все пилоты и их команды (включая пилотов без команд)
- **RIGHT JOIN**: команды и их пилоты (включая команды без пилотов)
- **FULL JOIN**: все пилоты и все команды (несопавшие значения = NULL)

Источник: пособие, стр. 106–110

### 2.2. Запрос с оператором DISTINCT

- Уникальные страны пилотов
- Уникальные страны трасс

Источник: пособие, стр. 104–105

### 2.3. Запрос с оператором BETWEEN

- Гонки в диапазоне дат (2024 год)
- Болиды с годом выпуска между 2020 и 2024

Источник: пособие, стр. 103

### 2.4. Запрос с оператором LIMIT

- Топ-3 пилота по очкам
- Первые 5 гонок по дате

Источник: пособие, стр. 105

### 2.5. Запрос с оператором OFFSET

- Гонки с 4-й по 6-ю (пропустить первые 3)
- Пилоты с 3-го по 5-е по количеству очков

Источник: пособие, стр. 105–106

### 2.6. Запросы с шаблонами поиска LIKE, NOT LIKE

- Пилоты, имя которых начинается на 'Ш'
- Пилоты, в имени которых есть 'о'
- Трассы, название которых не содержит 'Гран-при'
- Команды с названием из 4 символов (использование `_`)

Источник: пособие, стр. 101–102

### 2.7. Запросы с регулярными выражениями POSIX

- Пилоты из России или Италии (оператор `~`)
- Болиды, модель которых заканчивается на '-24'
- Трассы, название которых содержит цифру
- Пилоты, имя которых НЕ начинается на 'М' или 'С' (оператор `!~`)

Источник: пособие, стр. 102–103

### 2.8. Запросы с агрегированными данными (3 функции)

- Статистика по очкам пилотов: SUM, AVG, MAX
- Статистика по гонкам: COUNT, MIN, MAX длины трасс
- Статистика по бюджету спонсоров: SUM, AVG, COUNT

Источник: пособие, стр. 104

### 2.9. Запросы с вложенными запросами

- Пилоты, набравшие больше очков, чем среднее значение (подзапрос в HAVING)
- Пилоты, участвовавшие в гонке с ID = 1 (некоррелированный запрос с IN)
- Команды с количеством пилотов больше среднего (коррелированный запрос)

Источник: пособие, стр. 112–116

### 2.10. Запросы с условным выражением CASE

- Классификация пилотов по очкам (HIGH, MEDIUM, LOW)
- Статус гонки (прошедшая/будущая) на основе даты
- Категория длины трассы (короткая, средняя, длинная)

Источник: пособие, стр. 106

### 2.11. Запросы с группировкой и простой сортировкой

- Количество очков каждого пилота, сортировка по убыванию очков
- Количество гонок на каждой трассе, сортировка по убыванию количества
- Количество пилотов в каждой команде, сортировка по названию команды

Источник: пособие, стр. 104

### 2.12. Запросы с группировкой с условием и многоуровневой сортировкой

- Пилоты с суммой очков > 15, сортировка: очки DESC, имя ASC
- Команды с > 1 пилотом, сортировка: количество DESC, название ASC
- Трассы с > 1 гонкой, сортировка: количество DESC, длина DESC, название ASC

Источник: пособие, стр. 104

- Формулировки SQL-запросов
- Скрипты SQL-запросов
- Скриншоты выполнения SQL-запросов (пронумерованы)
